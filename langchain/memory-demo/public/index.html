SimpleFileChatMessageHistory
BaseListChatMessageHistory를 상속해 JSON 파일로 저장합니다. 서버를 재시작해도 대화가 유지됩니다.
File
class SimpleFileChatMessageHistory extends BaseListChatMessageHistory { constructor(sessionId) { super(); this.filePath = `chat_histories/${sessionId}.json`; } async getMessages() { const data = await fs.readFile(this.filePath, "utf-8"); return JSON.parse(data).map(toMessage); } async addMessage(message) { const messages = await this.getMessages(); messages.push(message); await fs.writeFile(this.filePath, JSON.stringify(messages)); } }
✅ 서버 재시작에도 유지
📁 파일 I/O로 약간 느림
🖥️ 같은 디스크 내에서만 공유
💬
대화를 시작하세요

RedisChatMessageHistory
Redis List에 저장됩니다. TTL 만료, 여러 서버 간 공유가 가능해 프로덕션에 적합합니다.
Redis
class SimpleRedisChatMessageHistory extends BaseListChatMessageHistory { constructor({ sessionId, url, ttl }) { super(); this.key = `chat_history:${sessionId}`; this.client = new Redis(url); this.ttl = ttl; } async getMessages() { const raw = await this.client.lrange(this.key, 0, -1); return raw.map(toMessage); } async addMessage(message) { await this.client.rpush(this.key, JSON.stringify(message)); if (this.ttl) await this.client.expire(this.key, this.ttl); } }
✅ TTL 만료 지원

🕸️ LangGraph StateGraph
명시적 그래프형 — 상태·노드·엣지를 직접 정의
const graph = new StateGraph(GraphState) .addNode("llm_node", llmNode) .addNode("tool_node", toolNode) .addEdge(START, "llm_node") .addConditionalEdges("llm_node", shouldContinue, { tools: "tool_node", [END]: END }) .addEdge("tool_node", "llm_node") .compile({ checkpointer });

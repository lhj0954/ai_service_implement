LangChain Agent Tools 실습

@langchain/langgraph · createReactAgent ReAct Pattern
Agent가 보유한 4가지 Tool
질문에 따라 Agent가 자동으로 적절한 Tool을 선택해 실행합니다 (ReAct 패턴)
createReactAgent
const agent = createReactAgent({ llm: model, tools: [getCurrentTimeTool, getWeatherTool, getAINewsTool, searchPDFTool], messageModifier: "질문에 따라 적절한 도구를 선택해 한국어로 답변하세요.", }); const stream = await agent.stream( { messages: [new HumanMessage(question)] }, { streamMode: "updates" } );
🕐
get_current_time
현재 한국 날짜와 시간을 반환합니다
예: "지금 몇 시야?", "오늘 날짜가 뭐야?"
🌤️
get_weather
특정 도시의 현재 날씨 정보를 조회합니다
예: "서울 날씨 어때?", "부산 오늘 비와?"
📰
get_ai_news
최신 AI 기술 뉴스와 동향을 검색합니다
예: "GPT-5 출시 소식", "구글 AI 최신 뉴스"
📄
search_pdf_document
업로드된 PDF에서 회사 규정을 검색합니다
예: "연차 규정", "복지 혜택이 뭐야?"
PDF 문서 업로드 (Tool 4 사용 시 필요)
회사 규정, 매뉴얼 등 PDF를 업로드하면 Agent가 문서 검색 도구를 사용할 수 있습니다
